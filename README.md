# 🌸 Pollinations StretchText Browser Extension

> Built for **[POLLEN-QUEST #17998](https://github.com/pollinations/pollinations/issues/17998)**: A browser extension that turns any web page into stretchtext.

## 🎯 What it does
Inspired by Ted Nelson's 1967 StretchText vision and modern Claude Code mods (`cc-stretch`), this browser extension collapses long-form web reading into tight, high-signal sentences with interactive inline expansions. 

- **1/6th Reading Friction:** Automatically condenses paragraphs into the opening thesis statement.
- **Interactive Inline Unfolds:** Click `[+]` to unfold depth right where it stands without page reloading or disruptive popups.
- **Pollinations Powered:** Designed for seamless BYOP (Bring Your Own Pollen) integration using Pollinations text models.

## 📦 Installation
1. Clone or download this repo.
2. Open Chrome/Edge ➔ Navigate to `chrome://extensions/`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select this directory.
5. Click the extension icon on any article and hit **Transform This Page**!
